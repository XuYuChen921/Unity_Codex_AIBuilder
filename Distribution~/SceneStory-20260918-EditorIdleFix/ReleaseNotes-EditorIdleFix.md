# 编辑模式持续卡顿修复 · 2026-09-18

针对静态 Mesh 地面绑定后，未播放时编辑场景或拖动 Scene 视角卡顿的问题。

- 路线显示改为变化触发，不再每秒重建约五次全部路线。
- 路径控制数据、选择片段、撤销、场景对象、资源或地面变化时刷新缓存；普通视角移动沿用缓存。
- 轻量控制点检查兼容脚本直接移动点位，避免缓存导致路线显示不更新。
- 层级点位可见性改为变化触发，避免每半秒无条件遍历。
- 保留上一包的地面绑定进度、取消、分页及重复采样优化。

验证：独立发布工程 84/84 Editor 回归测试通过。2000 个网格、41 条路线的合成场景中，100 次空闲检查合计约 0.001 秒，额外路线重建次数为 0；移动控制点、改变地面后正常重建。

这不是用户恐龙场景的实际 FPS 测量，仍需在该场景中拖动视角确认改善。修复已同步到恐龙工程与发布工程，不改变场景当前地面绑定模式，不修改或保存场景资产。
