# 场景剧情：增量刷新性能优化

- 保留未受影响路线的显示缓存；无关对象变化不再重复采样所有路线。
- 同一剧情轨道的路线保留前后连接依赖，移动节点时更新相关路线，不影响其他角色的缓存。
- 一次遍历收集路线归属、角色颜色与依赖，避免每条路线重复扫描整个场景。
- 手柄缓存改为按路线直接查找；未改变的 Game 辅助线不重复写入 LineRenderer。
- 路径点与停留点同步共用剧情对象查询，清理缓存时使用集合查找。
- 保留贴地采样精度、全部节点的显示和点选能力，不改场景路径数据。

完整安装包，可首次安装或覆盖更新。

## 验证
Unity 2022.3.62f3，103 项编辑器测试通过。
同一验证工程中，2000 个地面网格、41 条路线，连续强制触发 5 次内容未变的刷新：
- 优化前：15.151 秒，200 次路线重采样。
- 优化后：0.025 秒，0 次路线重采样。
首次地面同步约 1.1 秒，30 次播放求值约 1.52 秒，基本持平。
这是合成压力测试的代码路径耗时，不是恐龙实际场景的帧率或 GPU 数据。未在用户复杂场景中完成静止、转视角、拖动和播放四种状态的现场 Profiler 验收。
