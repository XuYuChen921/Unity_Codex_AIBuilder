# 场景剧情工具包 1.0.0

适用 Unity 2022.3，依赖 Timeline 1.7.7。安装方式二选一。

## 推荐：直接导入 unitypackage

1. 在目标项目的 Package Manager 安装 Timeline。
2. 导入 `SceneStory-1.0.0.unitypackage`。
3. 打开 `Assets/SceneStory/Samples/BasicExample/BasicStory.unity`。
4. 选中“基础剧情（选我编辑）”，打开 `Tools > 场景剧情 > 打开编排窗口`。
5. 打开原生 Timeline，点击播放或拖动时间预览。动画轨上的重叠区控制过渡。

## UPM 安装

Package Manager 左上角“+”选择“Add package from tarball”，选择 `com.xuyuchen.scene-story-1.0.0.tgz`。
在包的 Samples 中导入“基础几何体剧情”，打开导入的 BasicStory 场景。

已包含本套剧情代码的 AIBuilder 工程不要重复导入独立包，以免类型和 GUID 冲突。当前 AIBuilder 工程已经可以从同名菜单使用这些功能。

## 示例内容

示例只使用 Plane、Capsule、Cube，包含 5 个路线/停留片段和 3 个动画片段：

- 0–2 秒：原地放大、缩小。
- 2–6 秒：沿平滑曲线贴地移动。
- 6–8 秒：停留并旋转。
- 8–12 秒：不贴地的空间移动。
- 12–14 秒：空中停留。

动画轨预设 0.4 秒重叠过渡。内置样例材质为 Built-in；URP/HDRP 工程推荐通过菜单“创建基础示例”重新生成当前管线的材质。

## 菜单

主要入口：打开编排窗口、为选中对象创建剧情、创建基础示例、地面绑定设置、使用教程。
“剧情移到零秒”和“显示未使用剧情对象”归到维护子菜单。旧模型示例、开发工作台和一次性修复入口不在通用包中。

详细教程：`package/Documentation~/使用教程.md`，也可以直接在 Unity 中打开“使用教程”窗口。
