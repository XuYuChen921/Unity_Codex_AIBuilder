场景剧情工具包 · 使用教程
适用：Unity 2022.3；依赖：Timeline 1.7.7。

1. 导入与打开
新工程推荐导入 SceneStory-1.0.0.unitypackage；先通过 Package Manager 安装 Timeline。
也可从 Package Manager 的 Add package from tarball 导入 UPM .tgz，依赖会随包声明安装。
两种安装方式选一种。本工程的 AIBuilder 已包含同一套剧情代码，不要重复导入独立包；原脚本 GUID 和类型保留用于兼容已有资产。
工具入口：Tools > 场景剧情。

2. 先体验基础示例
选择“创建基础示例”。工具在 Assets 下创建独立 SceneStoryExample 文件夹；重复创建使用新文件夹，不覆盖旧示例。
示例只使用 Plane、Capsule、Cube 和生成的普通材质、动画，无外部模型。
0–2秒：原地放大缩小；2–6秒：曲线贴地移动；6–8秒：停留旋转；8–12秒：不贴地的空间移动；12–14秒：空中停留。
Timeline 第一行控制路线与停留，第二行控制 Pulse（缩放）和 Spin（旋转）。6秒和12秒附近有0.4秒动作混合区。
不运行场景也可点 Timeline 左上角播放。暂停后在当前时间框输入秒数，或用逐帧按钮准确定位。
示例是编排教学，不是步态或脚部IK演示；缩放、旋转动画不要开启距离步态同步。

3. 为自己的对象创建剧情
在 Hierarchy 选中一个场景模型，点击“为选中对象创建剧情”，选择新的 Timeline 文件位置。
工具增加单位缩放的路线驱动父对象，保留模型，并复用模型已有 Animator；没有时创建 Animator。
角色结构为：路线驱动根对象 > 含 Animator 的模型 > 动画节点。路线改变外层位置，动画改变内层姿态。
新剧情含一个停留片段和一条空动画轨。把模型对应的 AnimationClip 拖入动画轨。
动画路径必须匹配 Animator 下的层级。示例动画只针对 Visual 子节点，不能直接套用任意模型。
当前骨架动作以 Generic 为验证范围；不支持把 Humanoid 重定向或复杂脚锁作为已验证功能。

4. 添加、排序和删除片段
打开“编排窗口”，剧情对象选择对应的 PlayableDirector。
用“+ 移动表演”和“+ 停留表演”添加片段。拖列表左侧手柄排序，保留各段时长并首尾相接。
选中行后可删除、复制、定位预览、选中路线或停留点。删除支持Ctrl+Z，未使用的生成节点会自动隐藏。
维护菜单可临时显示未使用对象，或把整个剧情连同动画轨一起前移到零秒。
路线排序、删除、改时长不自动重排独立动画轨；请在 Timeline 同步安排对应动作。

5. 编辑路线与停留
选择移动片段后点击“选中路线/停留点”，在 Scene 点击路线节点并拖动坐标轴。
路线使用平滑曲线，可增加中间控制点；默认按 Timeline 顺序连接上一段终点。
停留默认跟随前段终点，连续停留向前寻找位置来源。开头连续停留以第一个停留点为基准。
只有起始或关闭自动跟随的独立停留点需要手动摆放。不要通过模型的外层位置代替修改路线。

6. 地面与空间路径
“地面绑定设置”指定地面查找根对象和名称，例如根对象 Environment、名称 Ground_、匹配方式“以此开头”。
点击“应用设置并重新绑定地面”。工具为匹配 MeshFilter 创建/更新 MeshCollider，旧绑定在未匹配时保留。
对象名称由你指定，不依赖固定FBX文件名；重新导入FBX或Prefab后会安排更新。
本版自动匹配网格地面；Unity Terrain 地形可手动把 TerrainCollider 指给路线 groundSurfaces。
每个移动片段独立勾选“本片段贴合地形”；关闭后按节点真实XYZ走空间曲线，适合起飞或飞行。
空中片段仍沿用水平朝向，不自动实现俯仰、侧倾或飞行物理。

7. 速度、动画与过渡
移动片段时长越短、路程越长，平均速度越高。移动速度Curve横轴0–1代表本段时间，纵轴为相对速度。
曲线按面积分配路程，仍保证按时到达终点。负值按零处理，不能整条为零。
在动画轨让两段动画重叠可混合过渡；混合曲线、Clip In和手动倍率在Timeline Inspector调整。
移动面板的“入场朝向缓转”只控制转向，不替代动画轨的混合。
循环走路/跑步动作可勾选“动画跟随移动距离”，校准“一循环前进距离”。距离和时长变化时步频自动调整。
默认1米是待校准值；同步模式忽略手动动画倍率，Clip In用于起步相位。吃东西、观察、缩放、旋转、拍翅等动作保持关闭。
没有自动走跑切换，没有脚部IK锁定；坡面和急转弯可能仍有滑步。

8. 保存与常见问题
场景保存对象、路线节点和地面引用；Timeline保存片段与动画配置。编辑后保存场景和Timeline。
示例材质根据创建时的渲染管线生成。切换Built-in/URP/HDRP后，按管线转换材质，或重新创建示例。
无法播放但能拖动：检查剧情Director是否被其他脚本改成Manual。本工具编辑状态会修复自带运行驱动的时钟。
角色不动：检查剧情轨是否绑定StageActorDriver；没有动画：检查动画轨Animator绑定及动画节点路径。
编辑器预览和运行驱动不要同时抢同一对象；结束一方预览后再进入另一方。
通用基础示例和编排逻辑经过测试，不等同于任意导入骨架、地形或设备均已验收。
