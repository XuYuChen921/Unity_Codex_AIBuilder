# Scene Story 场景剧情 1.0.0

Unity 2022.3 / Timeline 1.7.7。入口：Tools > 场景剧情 > 使用教程。

UPM：Add package from tarball 安装 .tgz；在 Samples 导入基础示例，或用菜单创建当前渲染管线适用的新示例。

.unitypackage：先安装 Timeline，再导入。两种方式选一种。不要与已含剧情代码的 AIBuilder 同时安装。

源代码和 GUID 保留兼容已有剧情；本包不含 ProBuilder、URP 插件、模型、纹理或中华龙鸟素材。

详细操作见 Documentation~/使用教程.md，或 Unity 内使用教程窗口。
