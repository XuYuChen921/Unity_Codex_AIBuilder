Documentation

Installation, workflow and troubleshooting

Requires Unity Timeline. Supplied store scenes use Built-in materials. Check the package compatibility report for tested editor versions and pipelines.

What it covers

Authored routes, ground filtering, facing curves, animation tracks and optional gait synchronization. It does not provide automatic pathfinding, obstacle avoidance, dialogue, camera direction, foot IK or animation retargeting.
