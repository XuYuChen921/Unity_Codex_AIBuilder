# Deployment handoff

This is a static site. Upload the contents of this folder to the publisher-owned HTTPS hosting location. No build step, server-side code, API keys, forms or database are required. Keep index.html and QuickStart.md together. Set the resulting public URL in the publisher profile; no URL has been invented or registered.

The site has not been deployed. Local-file browser preview was blocked by the browser tool URL policy, so rendered desktop/mobile acceptance remains pending. Source and local link checks have been completed. Before public deployment, open index.html in a browser yourself, check narrow and wide layouts, the quick-start link and the support mailto link, then supply the real HTTPS URL.

No account credentials, payout details or personal identity data belong in this folder.
