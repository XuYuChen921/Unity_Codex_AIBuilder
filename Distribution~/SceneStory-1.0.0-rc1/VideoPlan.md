# 演示视频拍摄清单

所有画面使用候选包的实际操作录屏，不使用效果图充当运行效果。字幕提供中英两版。

## 90 秒介绍

0–10 秒：三个几何体角色在同一 Timeline 中协同移动，展示最终结果。
10–25 秒：选中一个物体，一键加入角色；添加停留和移动。
25–40 秒：选中中间片段插入，再拖动排序，展示连接更新。
40–55 秒：在 Scene 中点击不同角色的点，展示轨道切换和路线配色。
55–70 秒：展示斜坡、Cube 和上方平面；扫描排除植被。
70–85 秒：设置转向后回正、贴地过渡，播放动画与声音。
85–90 秒：显示名称、验证过的 Unity 版本、Timeline 依赖、教程入口。

## 商品截图

1. 总览：Scene + 主编排窗口 + Timeline。
2. 多角色：三种路线颜色和轨道。
3. 插入与排序：选中片段及结果。
4. 地面窗口：扫描、排除、包含列表。
5. 朝向曲线：转向、保持、回正关键点。
6. 动画/音频：Timeline 绑定清晰。
