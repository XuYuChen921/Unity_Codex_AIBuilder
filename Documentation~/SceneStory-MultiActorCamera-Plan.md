# 多角色剧情观察相机方案

记录日期：2026-09-18。

状态：用户已认可方案，仅记录，尚未实施。必须等用户明确通知后再开始开发。本次安装包不包含以下新相机功能。

## 目标与范围

将剧情观察相机扩展为编辑器内的多角色观察面板，用于同步检查角色的位置、动作和配合。第一版不接管正式游戏镜头；运行时镜头是否复用另行决定。

## 多画面观察

- 每个需要观察的角色绑定独立观察相机。
- 支持单画面、双画面、四宫格；更多角色翻页。第一版同时显示最多四路。
- 每格显示角色名与当前片段，支持放大和选中对应剧情角色。
- 所有画面由同一个 Playable Director / Timeline 时间驱动，统一播放、暂停与拖动时间。
- 相机按需渲染，不添加 AudioListener，不影响正式游戏相机。

## 独立调整与保存

- 默认观察目标位于角色上身，可指定头部、模型中心或自定义节点。
- 拖动调整环绕角度，滚轮调整距离，平移调整观察中心，支持重置。
- 每个角色独立保存距离、角度和观察点偏移。
- 默认只跟随角色位置，避免角色突然转身带动镜头；可选跟随角色朝向。

## 自动避障

分别保存用户设定的期望位置和避障后的实际位置。临时避障不覆盖用户设置，离开障碍后平滑恢复构图。

1. 从角色观察目标向期望相机位置检测障碍。
2. 被遮挡时先收近到障碍前。
3. 太近无法有效观察时尝试左右绕开或抬高。
4. 移动过程持续检测，避免在两个安全位置之间穿墙。
5. 检测范围考虑镜头近裁剪面，不仅检测相机中心。
6. 收近及时、恢复平缓，使用切换阈值减少狭缝中的反复摆动。

使用独立相机障碍层，纳入地形、山体和建筑，排除角色自身、触发器及剧情辅助点。可复用适合的已有碰撞体，但地面碰撞体不一定覆盖墙壁和山体侧面，需检查覆盖范围。

无有效碰撞体的网格不能可靠避障。极窄空间可能无法同时满足不穿模和完整观察角色，此时优先避免穿模，允许近景或局部遮挡，并提示观察空间不足。

## 分阶段实施

第一阶段：角色绑定、多画面同步预览、独立调整与保存、基本遇障收近。

第二阶段：左右绕行、抬高取景、狭缝防抖、遮挡提示，在用户山体场景中实际验证。

## 验收

- 多角色画面使用同一剧情时间，各角色视角调整互不影响。
- 拖动 Timeline 后取景位置正确，不依赖此前连续播放的状态。
- 相机进入狭缝时尽量维持安全视角，离开后恢复用户构图。
- 编译和自动测试不能替代山体场景、遮挡、穿模及画面抖动的实际验收。
