# 场景剧情工具：布局审查

日期：2026-09-16。范围：当前 dinosaurtosky_3.0_beta1 中的中文工具窗口、选中移动片段的属性区及地面绑定窗口。本次仅检查布局，没有修改工具代码或场景数据。

## 结论

保留深灰底色、青绿色选中态和紧凑片段行，优先改善信息层级与滚动方式。当前约 605 像素宽的停靠窗口中，顶部固定区域占约 430 像素；查看下方属性时，片段列表与选中片段标题会滚走。最值得改的是可用编辑空间和当前编辑对象的可见性。

## 检查路径与证据

1. 查看当前角色、播放控制及两条片段列表，见 [初始页面](01-current.png)。
2. 向下滚动查看移动、朝向和步态设置，见 [属性页面](02-properties.png)。
3. 对照地面绑定浮窗的参数、扫描结果和应用按钮；检查后将主面板滚回顶部。

## 建议顺序

| 优先级 | 当前问题 | 建议 |
|---|---|---|
| 高 | 标题、语言、对象、播放控制和角色操作占据过多固定高度 | 标题改为紧凑工具栏；语言和帮助放右侧；播放按钮、时间与拖动进度合并布局。目标将固定区控制在约 180–220 像素，需实现后实际验证。 |
| 高 | 向下看属性时丢失当前片段上下文 | 窄窗口固定显示“角色 / 片段编号、名称 / 时间范围”；列表和属性采用可调分区、独立滚动，避免统一长滚动。 |
| 高 | 朝向、贴地、步态混在高级区，难找特定参数 | 分成“基础”“移动与贴地”“朝向与衔接”“动画与步态”折叠组；按片段类型显示适用字段；常用项默认展开。 |
| 中 | 路径颜色独占整行，角色新增和管理分散 | 当前角色选择、颜色色块、加入角色和管理集中为角色工具区；颜色保留可点击入口与提示。 |
| 中 | 添加与删除视觉权重相同 | 保留直接添加停留、移动的入口，删除改为低强调操作；定位、复制放在选中片段标题旁。 |
| 中 | 地面绑定上部拥挤、下部大量留白，浮窗挡住场景 | 按“范围与过滤 → 检测参数 → 扫描结果 → 应用”排列；结果区列出计数及状态，说明应用不可用的原因；支持合理停靠。 |
| 低 | 平均速度显示很多小数，帮助文字密集且偏小 | 显示值保留 2–3 位小数，内部精度不变；统一单位与标签宽度。普通说明收进提示或展开说明，警告样式留给真实问题。 |

## 验证边界

本次审查覆盖当前中文窄停靠窗口和两个片段的数据状态；宽窗口仅核对布局代码。未验证英文长文本、不同系统缩放、键盘操作、长片段列表或运行性能，不作这些方面的通过结论。布局实施后应补查这些状态。
