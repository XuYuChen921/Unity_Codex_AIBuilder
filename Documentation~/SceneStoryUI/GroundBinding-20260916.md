# 静态 Mesh 地面绑定

已同步到 dinosaurtosky_3.0_beta1 的 com.xuyuchen.scene-story 包。

入口：场景剧情主面板、当前角色轨道下方的“地面绑定 · 扫描 / 排除植被 / 重新绑定”。路线 Inspector 也有入口。

流程：
1. 筛选方式选择“静态 Mesh（推荐）”；环境根节点为空时扫描当前场景。
2. 草木父节点拖入“排除对象”；需要额外踩踏的石头、斜坡或非静态行走面拖入“强制包含”。明确排除始终优先，强制包含可覆盖名称和 Static 筛选。未启用物体不加入。
3. 扫描预览显示每个 Mesh 是否加入及原因；可用 Scene 红绿框检查。
4. 应用绑定更新自动绑定路线，复用可用 MeshCollider，必要时新增 MeshCollider。支持 Undo。失败会回滚，空结果保留旧绑定。修改筛选结果或场景内容后需重新预览。

名称排除同时检查父节点，默认包括 grass、plant、vegetation、foliage、bush、tree、草、灌木、植被、树。关键词只是辅助，合并在同一 Mesh 内的草和地面仍需独立行走面。

新模式不改写路线控制点高度。默认向上吸附 0.5 米、向下寻找 100 米、最大坡度 60 度；以节点高度附近的表面优先，排除头顶超出范围的桥面。问题路线会报告名称与位置，并在显示采样失败处标红。坡道需合理设置节点高度和吸附范围；不是导航寻路或角色脚锁系统。

性能：路线采样缓存重建时，先筛出路线水平包围范围内的碰撞体，再进行各点射线检测。此前的 Scene 显示缓存保留。

兼容：原有配置默认继续旧版名称匹配，不自动把旧场景切成全静态绑定。静态模式只在面板应用时重新扫描，不会被模型导入自动重绑。可在创建首个移动片段前应用地面，新增移动路线继承已应用的地面集合。

验证：Unity 2022.3.62f3，StageStory EditMode 72/72 通过。覆盖排除优先、父节点关键词、扫描不增加碰撞体、静态检查、应用/撤销、草木已有碰撞不变、空结果保留、桥下/桥上区分、坡度与落差失败，以及既有路线/Timeline 回归。
