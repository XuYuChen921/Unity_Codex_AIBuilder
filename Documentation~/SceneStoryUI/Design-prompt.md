## 最终生成提示词

Use case: ui-mockup. Create a polished but realistically implementable Unity 2022 Editor IMGUI custom window for a Chinese scene-story authoring tool. Front-facing screenshot only, 1440x1000 landscape. Title 场景剧情, small subtitle SCENE STORY. Flat charcoal neutral Unity editor panels, restrained teal accent for moving clips and warm amber for hold clips, thin separators, consistent 8/16px spacing, crisp readable Chinese labels. No glass, gradients, decorative photographs or impossible rendering. Header shows scene object selector and 打开 Timeline. Under header a transport card with 播放预览, 恢复角色, time 00:07.20 / 00:18.00, horizontal segmented timeline overview and time slider, checkboxes 循环当前片段 and 顺延后续片段. Main body left 36% width card 剧情片段 with count badge 05, draggable ordered rows each two-line: number 01, 开场停留, 停留, 0.0–3.0 秒; 02 林间漫步, 移动, 3.0–7.0 秒 highlighted teal; 03 回望, 停留; 04 走向终点, 移动; 05 收尾停留. Left bottom buttons + 停留 / + 移动 and subdued 删除片段. Right 64% width inspector card 片段设置 / 林间漫步, small actions 定位路线 and 复制片段. Group labels 基本信息, 空间与动作, 速度与衔接. Standard Unity input fields (rectangular 3px radius), dropdowns, object references, toggle boxes and a Unity AnimationCurve editor field. Show editable name, start and duration fields, 表演类型, 场景路线, 本片段贴合地形, 平均移动速度, 移动速度曲线. Bottom subtle contextual help about Scene handles. Professional desktop authoring utility, high information density with comfortable breathing room. Output one full window visual concept, no device framing.
