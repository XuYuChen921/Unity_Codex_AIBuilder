# 选中后插入与路线重排

- 点击“＋停留 / ＋移动”在当前选中片段之后插入，新片段自动选中。空轨道仍从 0 秒开始。
- 为新增片段顺延当前角色的后续片段，即使关闭“顺延后续片段”也会为插入留出空间；其他角色的时间不变。原生独立动画轨及音频不自动重排。
- 新路线从选中片段的有效终点出发，地面设置继承此前最近的移动片段；连续自动停留仍跟随前段位置。
- 拖动列表重排保持原先按时长连续排列的规则。路线根据新的顺序计算连接起点和曲线衔接，不改写已有到达点或中间控制点；关闭自动连接的路线保持独立。
- 合并后优先根据启用的主 Director 计算连接，停用来源的重复引用不再干扰主剧情。
- 插入和重排支持 Undo；排序前退出工具和原生 Timeline Preview，锁定轨道或其他动画预览会阻止修改。
