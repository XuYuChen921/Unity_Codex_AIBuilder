# 多层地面误吸附修复

连续贴地采样原先按自上向下射线的最近命中选择表面，较大的向上搜索范围会让头顶平面覆盖脚下地面。

限制投射模式改为优先选择接近上一采样点高度的表面；当脚前方确实被候选物体挡住时，才优先踏上它的可走表面。因此路线可以跨过 Cube、连续爬坡，同时不因头顶存在另一块平面而跳层。起点仍按节点高度选择楼层。此修复针对独立 Collider 的多层候选，不保证单个合并 Mesh 内多个重叠表面的选择。

验证：StageStory EditMode 76/76 通过。新增测试在向上搜索范围为 100 米时，覆盖地板、Cube、头顶平面并存，候选绑定顺序反转，头顶平面移动，以及明确设置在上层的路线。原有直线/曲线连续坡面和跨片段连接测试通过。
