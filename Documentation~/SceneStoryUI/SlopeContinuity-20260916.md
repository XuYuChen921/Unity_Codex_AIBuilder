# 斜坡路径中断修复

原实现逐点以未投射的路线高度向上寻找地面；连续斜坡超过该高度加上吸附范围后，整条采样失败并显示虚线。

静态地面模式现改为：首点选择高度附近地面，后续按本次采样的上一地面点续走；向上探测范围同时考虑局部水平距离和允许坡度。在局部范围内优先接触上层可走表面，避免底层平面覆盖坡面。长路线增加采样密度。整段重新计算，不依赖播放历史。

自动连接下一片段使用前段实际贴地终点；切线查询期间的重入保留原控制点查询，避免递归刷新。原有非限制模式保持旧投射行为。

验证：StageStory EditMode 74/74 通过。新增直线及曲线测试覆盖：原始控制点高度为 0、默认上吸附 0.5 米的路线爬升到 3 米坡顶后下降；底层平面与头顶桥面同时存在；缓存失效后重复采样一致；上坡终点接下一片段无断裂。目标包已同步，Unity 重载成功；当前 Scene 实见跨越坡顶的连续路线。用户当前面板上升范围已设为 100 米，该值未被修改；现场截图不作为默认 0.5 米的验收证据。
