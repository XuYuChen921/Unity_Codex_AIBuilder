# 中华龙鸟场景剧情编辑：操作示例

## 打开

Unity 工程：`D:/Unity Project/AIBuilderTest`。

菜单 **Tools > AIBuilder > 角色剧情 > 打开场景剧情编辑示例**。首次看不到菜单时，在 Unity 中刷新资源（Ctrl+R），等待编译完成。

场景位于 `Assets/CreatureStage/Examples/StoryEditing/中华龙鸟_场景剧情编辑.unity`。已接入用户的 `Assets/CreatureStage/Source/Export.fbx` 白模和中华龙鸟动画。白模源文件未修改；地面碰撞器、颜色、LOD 显示设置只作用于独立示例实例。

## 先试一次编辑

1. 保持 Unity 未进入 Play，打开“场景剧情编排”窗口。
2. 选择“走到倒木前”，在 Scene 中拖动路线控制点；起终点对应场景里的停留点。路径会重新计算，路线点会投射到指定地面。
3. 修改片段时长。默认“改时长后顺延后续片段”已开启，后面的片段一起后移。
4. 在动作库中切换动画，或者直接拖入 AnimationClip。移动段绑定路线，停留段绑定位置和朝向。
5. 拖动“剧情时间”检查任意时刻，或点击“播放预览”。“循环当前片段”便于反复调整。
6. 点击“结束预览 / 恢复角色”，然后保存场景和项目。路线保存在场景中，片段时间和动作保存在配套 Timeline 资产中。

可以使用 Ctrl+Z 撤销路线和参数修改。“打开原生 Timeline”可直接拖动片段调整时间；不要同时开启两个窗口的预览。片段暂不支持重叠，请保持前后相接。

新增移动段、停留段或复制当前段后，可以继续扩展剧情。复制会建立独立路线/停留点。已有相邻段共享的停留点被移动时，会同时改变相连路线端点。

## 已编排的内容

示例共 44 秒、15 个片段、5 个停留点、4 条路线：起点觅食 → 走到倒木前 → 觅食 → 受惊 → 观察 → 再觅食 → 低伏跑向草丛 → 停下低伏 → 等待 → 探头 → 起身 → 走出草丛 → 再觅食 → 观察 → 离开。

这是一套可修改的示例节奏和位置。进入 Play 可以观看整段，暂停、拖时间或切换跟随视角；编辑路线请退出 Play。

## 速度曲线与动作衔接（2026-09-11 更新）

在“场景剧情编排”中选中片段即可调整：

- **平均移动速度（米/秒）**：按路线长度换算片段时长，默认自动顺延后续片段。路径变长但时长不变时，平均速度相应提高。
- **移动速度曲线**：横轴 0–1 表示本段从开始到结束；纵轴是相对速度。通过曲线积分分配路程，保证在片段结束到达终点。可用“匀速”“缓起缓停”预设，再点击曲线编辑关键帧。整体把曲线高度乘二不会让总路程翻倍；要整体提速，请改平均速度或时长。
- **动画倍率 × 动画速度曲线**：控制动画自身的快慢。横轴同样是本段归一化时间，曲线值 1 为原倍率、0 为暂停。使用积分得到动画源时间，因此加速/减速不会导致源时间突然跳变。
- **入场衔接（秒）**：默认 0.25 秒，将上段末姿态平滑混入本段并缓转角色朝向。设 0 为硬切，实际最多占本段一半时间。只在两个片段首尾相接时启用，不需要重叠片段。

曲线负值按零处理，不支持倒放；移动曲线不能全为零。数值积分使用 256 格固定采样，避免极窄尖峰。开启“按校准步幅同步”后，动画随移动距离推进，独立动画倍率和动画速度曲线不再生效。

当前 44 个中华龙鸟动画 Clip（含新增的 7 个）已按对应 FBX 文件名命名，保留 GUID 和动画子资产 ID，原始 FBX 二进制未修改。以后可在 Project 选择 FBX 或文件夹，使用 **Tools > AIBuilder > 角色剧情 > 动画Clip按FBX文件名命名**。多片段 FBX 会跳过，避免覆盖人工分段名称；导入配置备份位于工程 `Library/CreatureStage/ClipRenameBackup_*`。

## 自定义地面名称

菜单 Tools > AIBuilder > 角色剧情 > 地面绑定设置，会选中当前场景的设置组件。填写‘地面对象名称’，选择‘名称以此开头／名称包含此文字／名称完全一致’，然后点击‘应用设置并重新绑定地面’。例如 Ground_ + 以此开头会匹配 Ground_01、Ground_02。匹配 Hierarchy 中的对象名，忽略大小写，默认仍为 P2Terrain 前缀。保存场景后，后续导入 Export.fbx、重新打开场景或手动修复都会使用这份规则。空规则或未匹配到对象时保留现有地面绑定；路线点不改变。每个场景只保留一份设置。

验证：三种匹配方式、空规则保护、精确匹配一块地面/前缀匹配九块地面、未匹配保留引用、控制点不变，以及自定义设置保存重开均通过。

## 删除片段后的路线显示

在原生 Timeline 删除移动片段后，Scene 辅助线、端点标记与 Game 路线会按当前片段引用更新。只剩停留片段时不显示旧移动路线。共享路线只要仍被其他移动片段使用就保留显示；Ctrl+Z 撤销后会恢复。路线对象与控制点不自动删除。已验证删除、撤销、共享引用，以及 12 项剧情回归测试。

## 新路线自动贴地

新建移动片段直接使用场景地面配置，不再要求保留旧移动片段。已有空绑定路线也会重新绑定。在路线 Inspector 中，‘自动绑定场景地面’默认开启；关闭后保留手动地面或悬空路线。直线路线同样沿途采样地形。新建路线的起终点会投射到地面，后续拖动控制点继续自动贴地。

自动贴地更新：自动地面绑定会同步控制点和起终点高度，保持水平位置不变，避免节点浮在路径上方。关闭‘自动绑定场景地面’可保留手动高度。旧说明中的‘控制点不变’现在指不改变水平布局；自动模式会调整高度。已验证无旧片段的新路线绑定、沿途地形采样与节点高度。

## 圆滑路线和转弯

路线使用自动控制柄的三次贝塞尔曲线，继续穿过已有节点并投射到地面。选择路线后，在 Inspector 勾选‘圆滑曲线’，通过‘圆滑度’0–1 调整弧度，默认0.5；0为直线。‘圆滑连接相邻移动片段’会在同一轨道上、时间首尾相接且路线端点水平重合的移动片段之间对齐切线；时间空隙或手动独立停留会中断圆滑连接；连续自动停留不切断空间曲线。恐龙朝向使用曲线切线连续求值。菜单‘角色剧情 > 圆滑当前剧情路线’可将使用中的路线统一设为0.5。保留节点位置，曲线可能偏离原折线，需要在窄通道检查通行范围。共享路线若在多个片段中的连接方向冲突，则不自动猜测其连接方向。

已验证：相邻移动路线切线连续、移动相邻节点后曲线缓存更新、关闭连接恢复独立曲线、圆滑度改变曲线形状、起终点不变与任意时间重复求值；剧情回归14/14通过。

## 停留位置自动跟随

停留片段默认开启“自动跟随上一段终点”。移动片段的终点调整后，后面的停留片段（包括连续多个停留动作）直接使用最新终点位置，不再跳到旧的独立停留点。按时间顺序解析，删除或重排片段后重新确定跟随来源，直接拖动时间轴也有效。跟随时使用来源路线的终点基础朝向，可通过当前片段“朝向偏移”调整。

开头连续的自动停留以第一段停留点为基准，这个点可以调整；后面的移动路线从该停留位置出发。自动跟随只向前查找，不再使用后面的路线起点。手动停留是明确的位置边界。需要独立位置时，关闭“自动跟随上一段终点”并设置停留点；旧的独立点引用保留作为备用。跟随状态下编排窗口显示终点标记，不提供独立位置拖动手柄，选中位置会定位到来源节点。从连续停留后新增移动片段，也会从实际停留位置创建起点。

验证：移动终点实时更新、连续停留、任意时间预览、首段停留、手动关闭跟随、重排和删除后的来源解析，以及原有剧情测试共16/16通过。已刷新主工程，未覆盖用户场景布局。

起始位置规则更新：第一段若为停留，以它的独立坐标为基准；若为移动，则从该路线起点开始。

## Timeline 重排后自动连接路线

路线默认开启“按 Timeline 顺序自动连接起点”。移动片段换到最前面、中间或末尾后，按当前时间顺序重新计算前后连接；中间的自动停留不会中断位置衔接。保留各路线的到达点、中间控制点和原始起点数据，不把自动连接结果写回场景锚点；撤销重排、删除片段后重新求值。剧情以移动开头时，首条路线使用自己的原始起点；以停留开头时，后面的路线连接起始停留位置。

自动连接的出发点不提供独立拖动手柄，修改上一段到达点即可同步更新。需要独立路线时关闭该选项。同一路线被多个移动片段共享时保留原始起点，避免为不同片段猜测互相冲突的连接。圆滑曲线、地面投射和播放沿用同一套有效路线节点。

## 节点选择与连续停留

选中路线后，点击节点小球切换编辑目标，只显示当前节点的一套移动手柄。Timeline 与编排窗口同步片段选择，选中普通 Transform 节点时不会再叠加整条路线的手柄。自动连接的起点和自动跟随的停留位置不能独立拖动，应调整其来源点。

自动跟随的停留片段沿 Timeline 向前查找：移动 → 停留 → 停留，两个停留都使用移动终点；停留 A → 停留 B → 停留 C → 移动，前三段都以可调整的 A 为基准，移动从 A 出发。后面再次遇到移动片段，则后续停留跟随新的移动终点。关闭自动跟随可显式指定独立位置。19 项剧情测试通过。

## 圆滑曲线与停留、重排的组合回归

已修复自动停留导致两点路线退回直线的问题：曲线沿 Timeline 顺序跨过连续自动停留寻找相邻移动路线，在共同位置对齐贝塞尔切线。角色在停留处暂停，前后路线仍保持圆滑。手动独立停留、时间空隙、关闭圆滑连接或不重合的端点仍为连接边界。

组合测试覆盖一个/三个连续停留、自动连接起点、移动目标点后的曲线缓存更新、反向重排、停留位置采样及手动边界。剧情回归21/21通过，主工程 Scene 已检查圆滑连接恢复。

## 列表拖拽排序

在场景剧情编排窗口，按住片段行左侧的拖动柄上下拖动，松开后完成排序。保留每段时长、动作、速度曲线和场景引用，以原来最早的开始时间为起点重新首尾相接（消除空隙和重叠）。Ctrl+Z 可恢复排序前的顺序和时间。路线、连续停留和圆滑连接按新顺序更新。

已在主工程实际拖动短停留片段并撤销恢复原顺序。播放求值读取轨道当前顺序，避免撤销后旧播放图误报片段重叠。

## 剧情对象列表自动整理

编辑模式下，Hierarchy 每半秒按当前 Timeline 更新工具生成对象的可见性。保留当前使用的路线、到达点、独立起始点；旧路线、旧节点和自动跟随时的备用点隐藏。删除、撤销、重排或切换独立停留后自动重新匹配。只整理剧情根对象下的路线和已识别的纯坐标点，不删除对象、不改变位置和引用，不修改模型及装饰对象。

需要查看备用对象时，打开菜单 Tools > AIBuilder > 角色剧情 > 显示未使用剧情对象；再点一次恢复自动隐藏。隐藏不减少文件中的对象数量，用于保留撤销与备用引用。已验证删除后隐藏、撤销后恢复、手动显示、有效引用与普通场景对象保留，剧情回归23/23通过。

## 面板内删除片段

在片段列表选中一行，点击列表下方“删除选中片段（后续时间前移）”。保留剩余片段的时长、动作和引用，以原来的剧情开始时间重新首尾相接，自动选中邻近片段并刷新路线和 Hierarchy。支持 Ctrl+Z 撤销；允许删除最后一段，空列表时删除按钮不可用。只删除片段，不销毁场景路线和节点。首段、中间段、末段、删空及撤销回归测试通过，剧情测试共26/26通过。

## 独立 Timeline 动画轨

菜单“Tools > AIBuilder > 角色剧情 > 拆分动画到 Timeline 独立轨道”，或编排窗口中的同名按钮，将现有动作迁移到 Unity 原生 Animation Track。当前场景已拆分：第一行控制路线与停留，第二行动画轨绑定角色子节点 Animator。原路线动作设置保留为备份，拆分后不再参与骨骼采样。请保存场景和 Timeline。

在第二行拖入 FBX 内的动画 Clip，移动片段调整开始时间，拖边缘调整长度；把后一段向前拖，让两段重叠，斜线区域就是混合过渡。选中动画片段，在 Inspector 调整 Clip Timing 的 Speed Multiplier、Clip In，以及混合曲线；重叠越长过渡越慢，可从0.2–0.5秒开始预览调整。拆分时按现有入场衔接时间预设重叠，前后动画在重叠区都继续播放。

动画与路线现为独立时间安排：本面板的移动速度曲线、排序和删除只操作路线与停留，不自动移动或删除动画轨片段。动作时间需要在 Timeline 同步调整。原动画倍率和循环设置迁移到原生动画片段；非匀速动画曲线和距离同步按拆分时的路线采样为60fps动画子资源，保留当时节奏，之后不会自动随路线长度变化重新烘焙。源 FBX 不修改。

已验证独立 Animator 绑定、重叠权重混合、路线片段没有动画时仍能移动、非匀速动画迁移、停止后角色根位置恢复，以及路径/停留/排序/删除回归，共28/28通过。主场景已看到两行轨道及重叠区；具体动作接触、转身和步态效果仍需在该场景预览调整。

## 从零秒开始

当前场景路线轨与动画轨原先均从2.1667秒开始，已整体前移到0秒，保留两行的相对时间、时长与动画重叠。菜单“角色剧情 > 将剧情整体移到零秒开始”可再次去掉片段前的空白，支持撤销。

运行初始化与“从头播放”会立即求值0秒，同一帧不推进；加载或切换窗口产生的长帧单次最多推进0.1秒，避免数秒加载耗时灌入剧情。正常帧按实际非缩放帧时间推进；长卡顿后不会追赶跳过剧情，因此真实墙钟时间可能较长。29项剧情测试通过。

## 飞行路线：贴合地形开关

选中移动片段，在编排面板取消“贴合地形”；也可选中 StageRoute，在 Inspector 修改同名开关。默认开启，保留现有地面生物行为。关闭后，节点拖动、贝塞尔曲线采样和角色位置直接使用节点 XYZ 坐标，地面更新不修改该路线高度，已有地面绑定可保留。开关切换会刷新路径采样缓存。已贴地的节点不会凭空恢复旧高度，关闭后通过高度轴设置飞行高度。

“自动绑定场景地面”只控制地面引用维护，“贴合地形”控制是否投射到地面，两者独立。新增移动路线继承上一条移动路线的贴地与地面绑定设置。自动连接起点和停留跟随规则仍然有效；独立设置起点可关闭自动连接。此开关控制路径坐标，角色朝向仍沿用原有水平朝向规则。

已验证开关切换缓存、带地面绑定的空中 XYZ 采样、地面改变不影响空中采样、重新开启贴地，以及原有回归，共30/30通过。

## 每个移动片段独立选择贴地或飞行

编排面板中的开关现为“本片段贴合地形”，只影响当前移动片段。行走片段勾选，起飞/飞行/降落片段取消后编辑空中节点。即使多个片段共用路线，采样和路程计算也各自使用本片段的模式。已有片段默认沿用路线设置，保持兼容；修改面板开关后成为显式片段设置。原生片段 Inspector 的 Ground Mode 可选 InheritRoute（沿用路线）、Ground（贴地）、FreeSpace（自由空间）。

停留片段沿用其来源移动片段的实际终点；从地面路线接飞行路线时，使用前段投射后的终点，保留后段空中目标。共用路线只要有自由空间用途，自动地面修复不改写它的原始节点高度，地面片段仅在采样时投射。新片段继承最近移动片段的设置。

Scene 路线预览按 Timeline 选中的移动片段显示；共用路线未被选中时以第一个引用片段为预览基准。运行采样独立于编辑器选择。共用路线仍共用控制点；需要不同空间轨迹时，应创建独立路线。

## 动画随移动距离同步步态

选中移动片段，向下滚动到“动画步态同步”。面板列出与本段重叠的动画，分别勾选“动画跟随移动距离”，填写“一循环前进距离（米）”。启用后也可在 Timeline 动画片段 Inspector 调整这两项。只对循环走路、跑步动作开启；吃东西、观察、拍翅等动作保持关闭。默认 1 米是待校准值，不代表模型的真实步幅。

动画进度按实际路程 / 循环距离计算。改变路线、时长或移动速度曲线后自动更新，任意时间预览不依赖上一帧。贴地片段计算贴地路程，飞行片段计算空间路程。同步模式忽略 Timeline 的 Speed Multiplier，Clip In 保留为初始步态相位；关闭同步恢复原生时间播放。原生重叠长度、混合曲线、动作和偏移保留。

同一动画片段可以覆盖多个移动片段；停留和空隙期间同步步态暂停。连续且相接/重叠的相同动画，循环距离和 Clip In 相同则延续相位。不同走跑动画的过渡仍需在 Timeline 调整混合区，并按落脚姿态调整 Clip In。同步不会自动更换走跑动画，也不会重新排列动画片段。

校准方法：先用匀速直线路径预览，支撑脚随角色在地面上向前漂时，适当减小循环距离以加快步频；支撑脚在地面上向后滑时，增大循环距离以减慢步频。走路和跑步分别校准；相同动作的多个片段需要使用相同校准值。面板显示本段平均步态倍率，低于 0.5 或高于 2 倍时提示调整时长或更换动作，不强行限速造成新的滑步。极端转弯、坡面和动作姿态本身造成的滑步仍需脚部接触锁定，当前尚未实现。

已通过 35 项剧情 EditMode 回归，包括实际骨骼采样随距离/时长变化、反向拖动预览、速度曲线积分、停留、原生混合过渡、连续步态相位以及启用转换的撤销。

## 不进入 Play Mode 的 Timeline 预览

编辑状态下剧情 PlayableDirector 使用 Game Time；运行时 StageStoryPlayback 才接管 Manual 时钟，停止运行驱动后恢复原设置。旧场景中本工具自己的 Manual 剧情会自动修正，请保存场景。其他自定义手动 Timeline 不受影响。

在 Timeline 左上角点击播放三角形即可预览，无需点击 Unity 顶部的运行按钮。需要准确定位时，暂停后在 Timeline 播放控件右侧的当前时间框输入秒数（例如 39.8），也可使用前后逐帧按钮。编排面板的时间显示会跟随原生 Timeline 的预览时间。

已在实际工程验证编辑模式下点击播放可推进时间并播放动作，暂停后精确输入 39.8 秒时两处时间一致；37 项剧情 EditMode 回归通过。此次只调整预览时钟及时间显示，不改变路线、片段时间或动画过渡。
